# JOTA HOUSE MANAGER

Sistema de ventas e inventario conectado a Supabase.

## Publicar con GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio público de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`; luego guarda.
5. GitHub mostrará la dirección pública del sistema. Ábrela desde el teléfono e inicia sesión.

No uses la clave `service_role` de Supabase en este repositorio.
